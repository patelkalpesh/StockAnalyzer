# 📈 Stock Portfolio Analyzer

Personal stock portfolio tracker and analysis tool built with Streamlit.

## Features
- 🏠 Portfolio Dashboard — Live prices, P&L, charts
- 🔍 Stock Analysis — Score any stock 0-100 with BUY/SELL recommendation
- ⚔️ Compare Stocks — Side-by-side comparison before buying
- ➕ Add/Remove — Manage holdings easily
- 📊 Mutual Funds — Track MF investments
- 🔔 Alerts — Price alerts and export

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data Source
Yahoo Finance (free, no API key needed)
